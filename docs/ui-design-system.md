# UI Design System

## 尺寸章程

| 用途 | 控件高度 | 图标尺寸 |
| --- | ---: | ---: |
| 元信息、状态、次级箭头 | — | 12px |
| 紧凑工具栏、输入区 pill | 32px | 14px |
| 标准导航、普通按钮 | 36px | 16px |
| 空态、主视觉 | — | 20px 以上 |

输入区工具栏统一使用 32px 高度、6px 间距、14px 图标。图标不承担装饰头像语义；Agent 来源以文本、类型和状态表达。

## Pill 规则

- 同一工具栏内 pill 共用高度、圆角、边框和字号。
- 选中态只改变前景/背景，不改变尺寸。
- 单一图标操作使用 32px 方形按钮；带文字操作使用左右 12px 内边距。
- 生成结果动作最多展示 3–5 个高频操作，详情与状态不伪装成按钮。

## 液体玻璃层

- 仅用于滚动域内的状态带、底部输入 dock 等浮层；不得遮断对话内容。
- 使用 `.pi-liquid-glass`：半透明渐变、`backdrop-filter` 饱和与模糊、内侧高光边缘。
- 背景透明度保持 0.2–0.5；内容仍以 `--foreground` 保证对比度。
- 灰阶 `--surface-subtle` 作为控件底色，不另造灰色值。
